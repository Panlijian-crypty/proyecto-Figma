# GLOBALTICKET

Proyecto de Programación Orientada al Usuario. Consiste en trasladar el diseño de una plataforma de venta de boletos de Figma a páginas web con HTML y CSS.

## Cómo abrir las páginas

1. Descarga el repositorio desde **Code → Download ZIP** y extrae la carpeta.
2. Abre la carpeta en **Visual Studio Code**.
3. Abre `crear-cuenta.html` o `iniciar-sesion.html` en tu navegador. También puedes utilizar **Open with Live Server** si tienes instalada esa extensión.
4. Cambia el ancho de la ventana para revisar la distribución en computadora, tablet y teléfono.

No es necesario instalar paquetes ni ejecutar comandos.

## Organización del código

Cada pantalla está reunida en un solo archivo `.html`:

- **HTML:** estructura, etiquetas, enlaces y campos del formulario.
- **CSS:** estilos incluidos dentro de las etiquetas `<style>` y `</style>`.
- **Imágenes:** integradas en el mismo archivo.
- **JavaScript:** mensajes de demostración al utilizar los formularios y enlaces de la vista previa.

## Alcance actual

La pantalla **Crear cuenta** reproduce el campo de nombre completo del diseño consultado. **Iniciar sesión** incluye correo electrónico y contraseña.

Las páginas son una maquetación visual: los formularios no crean cuentas, no autentican usuarios ni guardan datos. El buscador y los enlaces informativos todavía son parte de la demostración.
