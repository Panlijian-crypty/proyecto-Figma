# Proyecto Figma — GLOBALTICKET

Proyecto colaborativo para convertir el diseño de GLOBALTICKET en páginas web con HTML y CSS.

Este repositorio reúne el diseño de GLOBALTICKET y la documentación que utilizará el equipo para convertir sus pantallas de Figma en páginas web con **HTML y CSS**.

**Estado actual:** preparación y documentación. Se incorpora el diseño de Figma y se registran las responsabilidades confirmadas. La implementación de las pantallas comenzará después, cuando el equipo complete las indicaciones de la actividad.

## ¿De qué trata GLOBALTICKET?

GLOBALTICKET es una propuesta de sitio web para consultar eventos y realizar el recorrido de compra de boletos. El diseño contempla el acceso de usuarios, la consulta de eventos, el proceso de compra, los boletos digitales y un área de administración.

La intención es ofrecer una experiencia clara, con una misma identidad visual en todas las pantallas.

**Frase de la marca:** “Un click y experiencia inolvidable con tus favoritos es nuestro objetivo”.

## ¿De qué trata la actividad?

El trabajo consiste en tomar como referencia el proyecto diseñado en Figma y trasladar sus interfaces a HTML y CSS, de forma colaborativa.

Durante el desarrollo se trabajará en:

- Organizar el contenido y los formularios de cada pantalla con HTML.
- Reproducir colores, tipografías, tamaños, espacios y distribución mediante CSS.
- Mantener una presentación coherente entre las partes de cada integrante.
- Conectar las páginas del recorrido que se acuerde implementar.
- Adaptar la distribución a diferentes tamaños de pantalla.
- Registrar los avances del equipo en GitHub.

Las instrucciones completas que faltan por compartir se incorporarán a este README cuando estén disponibles. La lista definitiva de entregables y los criterios de evaluación quedan pendientes de esas indicaciones.

### Base visual trabajada

El trabajo previo de GLOBALTICKET definió la marca y la base visual que servirá de referencia para las pantallas:

- Nombre, logo y frase de la marca.
- Paleta de colores y tipografías.
- Variables y estilos para mantener consistencia.
- Botones y campos de formulario.
- Tarjetas de eventos y ventanas modales.
- Tablas y notificaciones.
- Criterios de espaciado, bordes y accesibilidad.

La base del diseño y la implementación web son etapas diferentes: contar con un diseño no significa que sus páginas ya estén desarrolladas.

## Pantallas y recorrido previstos

El alcance general de GLOBALTICKET contempla las siguientes áreas. La selección final para esta actividad se ajustará a las indicaciones que se compartan.

| Área | Propósito | Situación en esta etapa |
| --- | --- | --- |
| Inicio y exploración de eventos | Presentar la plataforma y permitir consultar eventos. | Dentro del alcance general del diseño; implementación por definir. |
| Detalle y selección de boletos | Mostrar la información del evento y las opciones de boletos. | Implementación por definir. |
| Iniciar sesión | Presentar la interfaz de acceso a una cuenta. | Asignada a Ariana. |
| Crear una cuenta | Presentar la interfaz de registro de usuarios. | Asignada a Lijian. |
| Carrito o resumen de compra | Revisar la selección antes del pago. | Implementación por definir. |
| Pago y confirmación | Presentar los datos del pago y el resultado de la compra. | Parte contemplada en el diseño previo; implementación por definir. |
| Mis boletos y boleto con QR | Consultar los boletos y su presentación digital. | Parte contemplada en el diseño previo; implementación por definir. |
| Administración | Presentar un panel para la gestión de la plataforma. | Parte contemplada en el diseño previo; implementación por definir. |

El recorrido de compra planteado es: **selección de boletos → carrito o resumen → pago → confirmación**.

Esta planificación describe interfaces y navegación. La autenticación real, el cobro de pagos, la generación de boletos válidos y el almacenamiento de datos no se dan por implementados ni se incluyen como compromisos de esta etapa con HTML y CSS.
